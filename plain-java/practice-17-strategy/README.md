## Практика 17 — Strategy

Задание: применить паттерн Strategy: создать интерфейс и две реализации с разными способами обработки данных.

В проекте используются:

- `PaymentStrategy` — общий интерфейс стратегии оплаты;
- `CardPaymentStrategy` — оплата картой;
- `CashPaymentStrategy` — оплата наличными;
- `PaymentContext` — класс, использующий выбранную стратегию;
- `Main` — демонстрация смены стратегии во время выполнения программы.
