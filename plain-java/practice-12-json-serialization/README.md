## Практика 12 — JSON Serialization

Задание: сериализовать объект в JSON и десериализовать обратно.

Эта практика использует Maven и библиотеку Jackson.

В проекте используются:

- `User` — класс пользователя;
- `ObjectMapper` — объект Jackson для преобразования Java-объекта в JSON и обратно;
- `pom.xml` — Maven-конфигурация с зависимостью Jackson.
