## Практика 19 — Observer

Задание: создать Observer-паттерн: один объект уведомляет другой об изменении состояния.

В проекте используются:

- `Observer` — интерфейс наблюдателя;
- `Subject` — интерфейс объекта, за которым наблюдают;
- `NewsPublisher` — издатель новостей;
- `NewsSubscriber` — подписчик;
- `Main` — демонстрация подписки, уведомления и отписки.
