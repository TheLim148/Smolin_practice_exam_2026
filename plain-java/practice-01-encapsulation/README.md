## Практика 01 — Encapsulation

Задание: создать простой Java-класс с методами для вычислений и показать принцип инкапсуляции.

В проекте используются классы:

- `Calculator` — выполняет простые арифметические операции;
- `BankAccount` — хранит данные банковского счёта и защищает поля через `private`;
- `Main` — демонстрирует работу классов.
