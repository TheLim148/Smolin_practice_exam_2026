## Практика 11 — Unit Test

Задание: написать unit-тест для метода сложения чисел в классе.

Эта практика использует Maven и JUnit.

В проекте используются:

- `SumCalculator` — класс с методом сложения;
- `SumCalculatorTest` — unit-тесты для проверки метода;
- `pom.xml` — Maven-конфигурация с зависимостью JUnit.
